# OP-002：仓库脚手架与前端基线

状态快照（非权威，以 `TASKS.md` 为准）：`DONE`

## 目标

建立可由 Windows 本机开发、由后续任务安全扩展的 OpsPilot 模块化单体骨架：锁定 Python/Node 依赖与质量门禁，提供自有 FastAPI 健康入口和采用官方 Agent Chat UI 固定基线的中文工作台壳；不交付任何诊断业务能力。

## 前置检查

## 范围

1. 建立 Python 3.12 的 FastAPI 后端包、测试目录、依赖锁和 lint/type/test 配置；只提供不含业务数据的进程健康与版本元数据入口。
2. 建立 Next.js/React/TypeScript 前端包、pnpm 锁文件、格式/lint/type/build 门禁，以及明确的开发代理/公开 API URL 配置。
3. 从官方 `langchain-ai/agent-chat-ui` commit `325517352ca3672c8bc0745c4143b2301dd74997` 复用许可允许的视觉组件、交互依赖和基础样式；保留来源和 MIT 归属。
4. 将前端替换为 OpsPilot 自有的 API/认证边界：不复制上游 `/api/*` passthrough、环境变量转发或 LangGraph 直连路径。
5. 预留 `agent`、`providers/mcp`、`skills`、`specialists` 的包边界、无实现的 `Protocol` 契约与功能开关 Schema；其余模块按 API/core/config 分层建立最小目录和导入边界。
6. 提供根目录开发命令、编辑器设置、忽略规则、许可证/来源记录以及可在无数据库、无模型、无目标系统时运行的本地门禁。

## 不在范围

- 不实现 Tool Gateway 的稳定工具或 Provider 映射、MCP Client/连接/工具发现、Superset 调用或降级逻辑。
- 不加载、发现或解析 Skill，不创建 `SKILL.md` 业务内容，不实现 Agent 节点、LangGraph 图、模型调用或 Specialist/委派逻辑。
- 不实现 RAG、PostgreSQL 模型/迁移、认证/RBAC、工单、审批、审计、故障真值、Docker Compose、目标系统或任何伪造业务返回。
- 不复制上游 API passthrough 或把其认证模型当作 OpsPilot 的认证方案。
- 不提前执行 OP-003 及后续任务，也不构建最终应用镜像。

## 实现与安全约束

- 遵循 ADR-003 的单向四层设计；当前 Agent/MCP/Skill/Specialist 文件只可定义类型边界，不能产生运行时业务行为。
- 后端使用 Python 3.12；跨层配置使用 Pydantic；真实密钥只留在被忽略的 `.env`，示例文件不包含密钥或本机私密路径。
- 前端只能调用同源开发代理或显式配置的 OpsPilot API 根地址；认证令牌和上游目标系统凭据不得由浏览器转发或暴露。
- 保留上游名称、固定 commit、许可证和接入范围；不把上游项目误称为 OpsPilot 自研。
- 不引入 Agent Redis、MinIO、Docker Socket、任意 Shell、任意 SQL 或模型文件。

## 验收条件

1. `tasks/OP-002.md` 完整说明范围、非目标、验收和验证命令，`TASKS.md` 在执行中标记 OP-002。
2. `uv lock --check`、`uv run ruff check .`、`uv run ruff format --check .`、`uv run mypy src`、`uv run pytest` 通过；健康端点测试证明不读取业务数据或第三方服务。
3. `pnpm install --frozen-lockfile`、`pnpm format:check`、`pnpm lint`、`pnpm typecheck`、`pnpm build` 通过；生产构建不含上游 API passthrough 路由。
4. 前端来源文件记录官方 URL、MIT 许可证、固定 commit、接入文件及保留范围；可在本地启动并呈现中文 OpsPilot 工作台壳。
5. 配置测试覆盖功能开关默认关闭和环境变量校验；Agent、MCP Provider、Skill Registry、Specialist 只能以无运行实现的契约形式存在。
6. 根目录 README 与开发命令、目录结构、环境示例、忽略规则同步；不提交 `.env`、模型、依赖缓存或构建产物。
7. 更新 `CURRENT_STATE.md`、`TASKS.md` 和 `handoffs/OP-002.md`，其中包含执行命令、结果、遗留问题以及 OP-003 启动条件；只检查 diff，未经所有者确认不提交、不 push。
