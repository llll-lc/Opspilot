# Security and scoped access

## Least privilege

Superset access decisions are scoped to resources and roles. This derived note directs an operator to verify the current denial and the specific resource within the authenticated scope; it does not identify a role change as the remedy.

## Boundary

An unavailable application and an access denial are separate observations. Missing metadata is not proof that a user should receive a permission. Changes to roles, datasets, dashboards, or exports require the later authorization and approval path.
