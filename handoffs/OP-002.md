- 运行 profile、内存/磁盘事实：本任务未启动 Docker、模型、Superset 或目标 Redis；前端生产构建只使用 Node 进程。

## 6. 设计取舍

- 选择一个 FastAPI 进程健康入口，而非虚构 incident、ticket 或 chat API；它能验证自有边界，又不抢占 OP-004/006/007 的领域职责。
- 只复用官方 UI 的 MIT 视觉原语，不复用其 LangGraph API passthrough；这样前端未来仍受 OpsPilot 服务端认证、授权和审计约束。
- 只创建空 Protocol 与配置开关，不预设工具/Skill/委派方法签名，避免 OP-003～009 的实测结论被脚手架锁死。

- 使用到的教程主题：前后端 API 边界、类型化配置、依赖锁、质量门禁、前端组件复用与供应链归属。
